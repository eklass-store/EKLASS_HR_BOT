# Structured Task Execution Rule

When working on modifications, bug fixes, or implementing a report of issues in this project, you MUST follow this strict execution rule:

1. **1 Edit = 1 Task**: Every single code modification or fix must be treated and recorded as an individual task in your `task.md` artifact. Do not combine multiple unrelated logical fixes into one task.
2. **10 Tasks = 1 Stage**: Tasks must be grouped into stages (مراحل). Each stage consists of exactly 10 tasks (or fewer if it's the final stage).
3. **Execution Pacing**: Execute and verify the tasks stage by stage. This ensures high accuracy, focus on details, and avoids rushing.

This is a mandatory rule for the EKLASS_HR_BOT project.
