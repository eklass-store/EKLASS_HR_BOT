# نظام Challengawy HR 🚀

نظام متكامل لإدارة الموارد البشرية (HR System) يعمل عبر **بوت تيليجرام** للموظفين، و **لوحة تحكم PWA** للإدارة. النظام مصمم ليعمل كخدمة (SaaS) متعددة الشركات بحيث تُستضاف كل شركة في بيئة Cloudflare مستقلة.

## التقنيات المستخدمة 🛠️
- **الخوادم:** Cloudflare Workers (بدون خوادم تقليدية Serverless).
- **قاعدة البيانات:** Cloudflare D1 (SQLite Edge Database).
- **البوت:** grammY (Telegram Bot API).
- **لوحة التحكم:** Vue 3 + Vite + Tailwind CSS + PWA.

---

## كيف تبيع النظام لشركات جديدة؟ (دليل التأسيس SaaS) 🤝
لتقديم النظام لعميل جديد بدون منحه وصولاً للكود المصدري الخاص بك، اتبع الخطوات التالية:

### 1. المتطلبات من العميل
- أن ينشئ حساب **Cloudflare** مجاني.
- أن يُصدر من إعدادات Cloudflare الخاصة به **API Token** يمتلك صلاحيات التعديل على (Workers, Pages, D1).
- أن ينشئ بوت تيليجرام من `@BotFather` ويسلمك الـ `BOT_TOKEN` واسم البوت.

### 2. النشر لحساب العميل (الإعداد اليدوي للشركة الأولى)
افتح سطر الأوامر (Terminal) في هذا المشروع ونفذ الخطوات التالية:

```bash
# 1. سجل دخول لحساب العميل مؤقتاً
npx wrangler login

# 2. أنشئ قاعدة البيانات الخاصة بهم
npx wrangler d1 create hr_db

# (انسخ معرف قاعدة البيانات database_id وضعه في ملف wrangler.toml الخاص بالعميل - إذا لزم الأمر)

# 3. ارفع الجداول الأساسية
npx wrangler d1 execute hr_db --file=./schema.sql --remote

# 4. انشر لوحة التحكم والباك إند
npm run deploy

# 5. سجل الخروج من حساب العميل
npx wrangler logout
```

### 3. إعداد الأسرار (Secrets) للعميل
من لوحة تحكم Cloudflare الخاصة بالعميل (أو عبر سطر الأوامر)، قم بإضافة الأسرار التالية لـ Worker:
- `BOT_TOKEN`: التوكن الخاص ببوت التيليجرام الخاص بهم.
- `ADMIN_PASSWORD`: كلمة مرور دخول الإدارة الافتراضية.
- `JWT_SECRET`: مفتاح تشفير عشوائي.

### 4. إعدادات مستقبلية (GitHub Actions)
لتجنب تكرار الخطوات اليدوية السابقة لكل شركة، سيتم مستقبلاً عمل ملف `deploy.yml` في مجلد `.github/workflows` ليقوم بالنشر الآلي لجميع العملاء عبر استدعاء الـ API Tokens الخاصة بهم المحفوظة في Github Secrets لديك.
